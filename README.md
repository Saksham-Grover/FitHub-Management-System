# FitHub Class Booking and Membership Management System
## About the Project
FitHub is a database-based application made to help manage fitness classes and gym members. The system is designed to handle class bookings, cancellations, attendance records, and general membership information.

## Technologies Used
The project uses the following technologies:
- Python
- MySQL
- Tkinter
- Pandas
- Matplotlib

## Main Functions
Some of the main features included in the system are:
1. Member Management
2. Staff Login and Authentication
3. Class Management
4. Booking and Cancellation Management
5. Search and Filtering
6. Data Visualisation
7. Excel Report Generation
